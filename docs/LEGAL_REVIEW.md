# Pre-release legal / policy checklist

This is an engineering checklist, not legal advice.

Before public distribution:

- Review Microsoft Services Agreement and Xbox-specific terms for the intended use/distribution model.
- Review Xbox trademarks and product naming before using Xbox branding in public-facing product names or artwork.
- Review the license and attribution requirements of every upstream component or copied/adapted source file.
- Add a `THIRD_PARTY_NOTICES` file when dependencies/source usage is finalized.
- Choose CaptureLink's own repository license only after the upstream and service-terms review.
- Add user-facing recording/privacy language before enabling recording in public builds.
- Avoid implying Microsoft endorsement or affiliation.
