# CaptureLink v0.1 Release Scope

## Included

- Microsoft/Xbox sign-in
- Console discovery
- Connect/disconnect
- Live Xbox video
- Live Xbox game audio
- Incoming in-game voice chat when present in the received stream
- Existing supported session controls
- Connection diagnostics
- Audio-only recording
- Video + audio recording
- Local file save
- Clear recording state

## Explicitly deferred

- Cloud relay/control plane
- Transcription
- GPULink integration
- Multi-user accounts
- Remote recording storage
- Editing suite
- Streaming to third-party platforms
- Cross-platform release guarantees
- Party Chat claims until separately validated

## Product positioning

CaptureLink is a local Remote Play viewing and capture utility. Recording should be presented as local capture of media received by the user's own Remote Play session.
